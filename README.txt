RUANG CEMERLANG — LANDING PAGE v1.3
======================================

ISI PAKET
- index.html: halaman utama Ruang Cemerlang.
- simulations/momentum/index.html: Simulator Tumbukan 1D.

PERUBAHAN v1.3
- Profil halaman utama kini hanya menampilkan "Intan Pratiwi Wardani — Guru Fisika".
- Simulator Tumbukan 1D asli sudah dipasang.
- Tombol "Buka Simulasi" pada halaman utama menuju simulator.
- Simulator memiliki tombol "Kembali ke Ruang Cemerlang".

CARA MEMBUKA DI KOMPUTER
1. Ekstrak ZIP.
2. Buka folder ruang-cemerlang-v1.3.
3. Klik dua kali index.html.
4. Pada kartu Momentum dan Tumbukan, klik "Buka Simulasi".
